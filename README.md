# Affordable Heating Cooling & Sheet Metal — human-designed production site

Pure static HTML + CSS with one tiny JavaScript enhancement for the copyright year.

No npm, Node, backend, database, API keys, tracking, paid dependencies, or build command.

Cloudflare Pages:
- Framework preset: None
- Build command: blank
- Output directory: `/`
- Keep `index.html` at repository root.

Google reviews:
The site uses a verified static snapshot and a direct live Google listing/reviews link.
It does not claim to automatically synchronize Google reviews. A genuine automatic
on-site Google review feed requires an approved external integration/API.

No custom domain is hard-coded, so the site can be connected to the business's own domain.

Design goal:
This version intentionally avoids the common AI-site pattern of a giant generic hero,
uniform rounded cards, repetitive three-column sections, excessive gradients and
template-like spacing. It uses a more editorial/local-business layout with varied
structure and restrained visual effects.
