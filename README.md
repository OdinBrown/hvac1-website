# Affordable Heating Cooling & Sheet Metal website

Static, dependency-free website ready for VS Code, GitHub, and Cloudflare Pages.

## Files
- index.html
- styles.css

## Deploy
Upload these files to a GitHub repository and connect the repository to Cloudflare Pages. No build command is required.

## Business data
Business information is centralized near the top of `index.html` and repeated only where needed for semantic markup and visible content.

## Reviews
The site uses a static, verified review snapshot plus a live Google Maps/listing button. It does not pretend to automatically synchronize Google reviews, because that would require an external API/backend.

## Domain
Once the business purchases its own domain, add that domain under the Cloudflare Pages project's Custom Domains section. The `pages.dev` URL remains available.
